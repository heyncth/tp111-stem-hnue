# S.A.F.E. HELMET — Landing Page

Trang giới thiệu dự án mũ bảo hiểm thông minh S.A.F.E — Đại diện Vòng Bán kết
Cuộc thi Khoa học Kỹ thuật & STEM 2026, Trường THCS & THPT Nguyễn Khuyến (Đà Nẵng).

- React 19 + TypeScript + Vite + Tailwind CSS v4 + Framer Motion
- 100% SVG nội tuyến + ảnh open-license tải local (`public/img/`, credit trong footer)

## Chạy thử

```bash
npm install
npm run dev      # phát triển
npm run build    # bản dựng vào dist/
npx vite preview
```
